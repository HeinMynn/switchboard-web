Local account manager for Chrome and Firefox

Switchboard is a purely local, privacy-first account manager. Every action happens entirely on your own device. There are no servers, no analytics, no remote code, and no cloud syncing. Your credentials never leave your machine.

How it works differently

Chrome

Save and restore named cookie snapshots. Maintains one active account per website across all normal windows. Switch & refresh existing tabs seamlessly.

Firefox

Leverages native container tabs for simultaneous accounts in the same window. Superior isolation with built-in Firefox features.

100% Local Storage

Credentials, cookies, and account settings remain entirely local on your physical device. Switchboard operates completely offline and never syncs, uploads, or transmits any of your data.

Complete Control

Easily rename, forget, or manually export cookies as JSON. Restore snapshots on demand without relying on automatic session restoration.

Install locally

Currently in developer preview. Build from source using Node.js 20+.

  1. Run npm run build
  2. Chrome: Load unpacked from dist/chrome
  3. Firefox: Load Temporary Add-on from dist/firefox
